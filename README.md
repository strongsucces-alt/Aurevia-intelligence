## 🚀 Deployment

Deze site is ontworpen voor **GitHub Pages** of elke andere statische hosting.

### GitHub Pages
1. Push naar de `main` branch
2. Ga naar repo **Settings → Pages**
3. Zet Source op "Deploy from branch: main, folder: / (root)"
4. ✅ Klaar!

### Lokale preview
```bash
python3 -m http.server 8000
# Of
npx serve .
```
