# Aurevia Intelligence 🌟

**Praktische AI die resultaat oplevert, geen technische hype.**

Officiële website van Aurevia Intelligence — een Nederlands AI-bureau dat complete automatiseringssystemen bouwt voor MKB-bedrijven.

🌐 **Live:** https://strongsucces-alt.github.io/Aurevia-intelligence/

## 📋 Inhoud

| Bestand | Beschrijving |
|---|---|
| `index.html` | Hoofdlandingspagina — diensten, cases, pricing, contact |
| `calculator/index.html` | Lead Leak Calculator (integraal onderdeel van de site) |
| `lead-leak-calculator.html` | Lead Leak Calculator (standalone versie voor direct delen) |

## 🔧 Techniek

- **Styling:** Tailwind CSS via CDN
- **Form handling:** Supabase (project: `aurevia-website`, tabel: `form_submissions`)
- **Hosting:** GitHub Pages (autodeploy op push naar `main`)
- **Geen dependencies / build-stap** — pure HTML/CSS/JS

## 🚀 Deploy

Push naar `main` → GitHub Pages deployt automatisch.

## 🎨 Branding

- **Primair:** `#002D5B` (Navy)
- **Accent:** `#D4AF37` (Goud)

## 📬 Contactformulier
